## 5. Dependencia arquitectónica UX03/UX05

Solicitud ejemplo (ilustrativa, **no** un dato experimental): «A si total con envío no excede X; en caso contrario B si hay stock y total no excede Y; si ninguna condición se cumple, no comprar».

**Hechos del código fijado:**

- Agent [ACPClient.get_offer](https://github.com/Tesis-Agentes-Comerciales/tesis-commerce-agent/blob/a11f78bd5e5c18cd3a81ab74c2edc96e274367af/src/commerce_agent/acp/client.py) llama a **POST /lab/offers/get** (extensión del laboratorio, no ACP estándar) y devuelve Offer con pricing.
- Merchant [PersistentCatalogReader.get](https://github.com/Tesis-Agentes-Comerciales/tesis-commerce-merchant/blob/abf30df3b6a611284dedcc26c00accac6a853329/src/commerce_lab/persistent_catalog.py) escribe el evento persistente **offer.read**, incluso al consultar. No es una cotización sin efectos.
- Merchant [CheckoutService.prepare_in_transaction](https://github.com/Tesis-Agentes-Comerciales/tesis-commerce-merchant/blob/abf30df3b6a611284dedcc26c00accac6a853329/src/commerce_lab/checkout.py) copia **offer.pricing** tras verificar vigencia y stock, para cantidad uno y contexto fijado. En update vuelve a leer precio de oferta. La correspondencia de código sugiere reutilizar la lectura previa como candidata de diseño, **no** demuestra equivalencia durante cambios concurrentes, expiración ni contra proveedores externos.
- El Agent aún no tiene una representación y orquestación validada de «prioridad A / fallback B si A es comercialmente falsa / abstención si A es técnicamente desconocida». El arnés no debe pasarle el ganador ni los totales del oráculo.

**Decisiones pendientes:** aceptar efectos de offer.read dentro del presupuesto experimental; validar identidad de snapshot/revisión/contexto; definir pruebas negativas (shipping, precio, stock, expiry, timeout, auth, concurrency); controlar reevaluación antes de preparar/autorizar; mantener separadas calibraciones A/B externas y decisiones reales del Agent durante E. No crear checkouts exploratorios ni una API nueva sin justificar necesidad.
